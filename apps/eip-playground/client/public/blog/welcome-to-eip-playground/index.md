# 欢迎来到 EIP Playground 🎮

EIP Playground 是一个创新的学习平台，通过**像素风格的互动游戏**帮助开发者深入理解以太坊改进提案（EIP）。

## 为什么选择 EIP Playground？

传统的技术文档往往枯燥难懂，EIP Playground 通过以下方式让学习变得有趣：

- **🎯 游戏化学习**：每个 EIP 都有对应的互动游戏，在玩的过程中掌握核心概念
- **🤖 AI 导师陪伴**：Dr. Panda 导师全程指导，解答疑问，提供即时反馈
- **🏆 NFT 成就徽章**：完成挑战后获得链上 NFT 徽章，证明你的学习成果
- **📚 漫画式讲解**：复杂的技术概念通过生动的像素漫画呈现

## 目前支持的 EIP

### ERC-8004: 可信 AI Agent 协议

通过 Agent Academy 游戏，你将学习：
- 如何铸造 AI Agent 身份
- 声誉系统的运作机制
- 机器人验证流程
- 通过导师问答测试你的理解

更多 EIP 游戏正在开发中，敬请期待！

## 开始你的学习之旅

1. 访问首页，选择感兴趣的 EIP
2. 阅读漫画了解背景知识
3. 进入游戏实践所学内容
4. 通过导师测试，获得 NFT 徽章

让我们一起在游戏中学习，在实践中成长！🚀
